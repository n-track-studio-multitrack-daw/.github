## Troubleshooting Common Issues

Install issues? Select the ASIO or Core Audio driver rather than the default system device.  
Performance problems? Increase the buffer during mixing and freeze tracks with heavy plugins.  
License/activation? Re-enter the licence key and reactivate after a hardware change.  
Compatibility? Re-scan the plugin folder if VST effects disappear after an update.  
Update failures? Restart before updating and keep a copy of the project file.
